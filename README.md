# littlerootsfoundation.org

Static site for Little Roots Foundation, served by GitHub Pages from the root of the `main` branch.

- `index.html` home page
- `research.html` research library (studies live in the `STUDIES` list inside the page)
- `cards.html` free card signup and downloads (`/cards/*.pdf`)
- `privacy.html` privacy notice
- `assets/site.js` email signup, posts to the Klaviyo client API (public company ID only)
- `CNAME` custom domain

Edit any page in the GitHub web editor and commit. Pages republishes in about a minute.

Rules: no em-dashes; no 501(c)(3) or tax-deductible wording until the IRS determination letter; materials teach skills and are not medical advice.

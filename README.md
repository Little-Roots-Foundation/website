# littlerootsfoundation.org

Static site for Little Roots Foundation, served by GitHub Pages from the root of the `main` branch.

- `index.html` home page
- `research.html` research library (studies live in the `STUDIES` list inside the page)
- `cards.html` free card signup and downloads (`/cards/*.pdf`)
- `privacy.html` privacy notice
- `assets/site.js` email signup, posts to the Klaviyo client API (public company ID only)
- `CNAME` custom domain

Edit any page in the GitHub web editor and commit. Pages republishes in about a minute.

Rules: no em-dashes; materials teach skills and are not medical advice; 501(c)(3) wording must match the IRS determination letter (Letter 947, Nov 4, 2026: public charity under 170(b)(1)(A)(vi), exempt from Oct 24, 2026); say "tax-deductible to the extent allowed by law", never promise a specific benefit; giving is live via Givebutter (VDACS registration submitted Nov 20, 2026, #24563); every page that asks for gifts carries the Va. Code 57-55.3 financial statement disclosure.
